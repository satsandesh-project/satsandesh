# SatSandesh AI — Speech (`services/ai/speech/`)

The real ASR service — not the mock. Loads `faster-whisper` (`small`, `int8`,
CPU) once at startup and serves `POST /v1/transcribe` against the
`contracts/ai/transcribe.py` contract.

**Only `wav_pcm16` is supported right now.** `ogg_opus` and `mp3` return a real
`PipelineError` (`AUDIO_FETCH_FAILED`), not a crash — decoding those needs
ffmpeg, which isn't installed on this machine yet. That's the next phase.

## Run it

```bash
cd services/ai
./.venv/Scripts/python.exe -m pip install -e .[dev]   # once, to pick up faster-whisper
PYTHONPATH=../.. ./.venv/Scripts/python.exe -m uvicorn speech.app:app --port 8002
```

Port **8002** — the mock server (`services/ai/mock/app.py`) already owns 8001,
so both can run side by side during development.

Startup loads the model and runs one warm-up inference before the process
reports ready — `GET /health/ready` returns `503` until both are done, `200`
after. `GET /health/live` returns `200` immediately regardless of model state.

## Configuration

Read once at import time by `services/ai/speech/settings.py`. A present-but-invalid
value fails fast and loudly at startup; a missing value falls back to the
documented default below — there is no silent, undocumented fallback.

| Env var | Default | Notes |
|---|---|---|
| `ASR_MODEL_NAME` | `small` | faster-whisper model size |
| `ASR_COMPUTE_TYPE` | `int8` | one of `int8`, `int8_float16`, `float16`, `float32` |
| `ASR_CPU_THREADS` | `4` | this machine has no CUDA GPU; 4 leaves headroom on a laptop CPU instead of pinning every core |
| `ASR_PORT` | `8002` | |

## Development

```bash
cd services/ai
PYTHONPATH=../.. ./.venv/Scripts/python.exe -m pytest speech/ -v
```

Tests load the real model (not mocked) against
`tests/fixtures/tone_2s.wav` — a synthetic 2-second 440Hz tone, mono
16-bit PCM at 16kHz, generated by `tools/generate_tone_fixture.py`. It exists
to exercise the decode → inference → response pipeline mechanically, not to
prove transcription accuracy — real-speech accuracy against recorded Telugu
samples is a later phase.
